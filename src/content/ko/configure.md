# 커스텀 설정

## 방법 1: 수동 편집

루트 디렉토리의 `starread.config.ts` 파일을 수정하여 웹사이트 제목, 탐색 메뉴, 작성자 정보, 사이드바 컴포넌트 표시 등 테마 설정을 커스터마이징할 수 있습니다.

예시 설정 항목:
```typescript
// 웹사이트 제목 수정
site: {
  title: '내 블로그',
  // ...기타 설정
}

// 커스텀 탐색 메뉴
nav: [
  { name: '홈', href: '/' },
  { name: '소개', href: '/about' },
  // ...기타 메뉴 항목
]
```

## 방법 2: GUI 편집

`pnpm dev` 명령어를 사용하고 탐색 모음에서 설정 버튼을 찾으세요

> [!warning]
>
> 이미지 등 정적 리소스와 관련된 파일은 public 디렉토리에 넣어주세요

매개변수를 조정한 후 설정 생성을 클릭하세요
