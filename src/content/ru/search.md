# Поиск

### Локальный поиск

По умолчанию используется локальный поиск, подходит для локального офлайн-использования, не требует настройки пользователем.

### Поиск Algolia

>[!important]
>В производственных средах рекомендуется использовать конфигурацию через переменные окружения, чтобы избежать раскрытия конфиденциальной информации в коде.

1. Отредактируйте `starread.config.ts`, чтобы выбрать поиск Algolia

```ts
export const themeConfig: starreadthemeconfig = {
  search: {
    // Поставщик услуг поиска: 'local', 'algolia'
      provider: 'algolia',
    }
}
```

2. Создайте и отредактируйте файл `.env` в корневом каталоге, пожалуйста, не отправляйте конфиденциальную информацию на сервер

>[!note]
>Для поиска Algolia требуются ваш идентификатор приложения Algolia, ключ поиска, имя индекса и ключ API администратора.

>[!tip]
>Если у вас нет учётной записи Algolia, вам нужно сначала зарегистрироваться и создать приложение. Учебник см. в [Vuepress 2 От 0 до 1 Продвинутый учебник для новичков — Глава полнотекстового поиска (включая Algolia, meilisearch)](https://blog.csdn.net/passwordgloo/article/details/134687291)

```txt
PUBLIC_ALGOLIA_APP_ID=Ваш идентификатор приложения Algolia
PUBLIC_ALGOLIA_SEARCH_KEY=Ваш ключ поиска Algolia
PUBLIC_ALGOLIA_INDEX_NAME=Ваше имя индекса
ALGOLIA_WRITE_API_KEY=Ваш ключ API записи (для загрузки индекса)
```

3. Отправить индекс в Algolia

Запустите `pnpm algolia`, чтобы отправить локальный индекс в Algolia
