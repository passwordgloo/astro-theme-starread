# Пользовательская конфигурация

## Способ 1: Ручное редактирование

Вы можете настроить конфигурацию темы, изменив файл `starread.config.ts` в корневом каталоге, включая заголовок сайта, навигационное меню, информацию об авторе, отображение компонентов боковой панели и т.д.

Примеры элементов конфигурации:
```typescript
// Изменить заголовок сайта
site: {
  title: 'Мой блог',
  // ...другие конфигурации
}

// Пользовательское навигационное меню
nav: [
  { name: 'Главная', href: '/' },
  { name: 'О нас', href: '/about' },
  // ...другие пункты меню
]
```

## Способ 2: GUI-редактирование

Используйте команду `pnpm dev` и найдите кнопку конфигурации в навигационной панели

> [!warning]
>
> Что касается статических ресурсов, таких как изображения, пожалуйста, поместите соответствующие файлы в каталог public

После настройки параметров нажмите «Создать конфигурацию»
