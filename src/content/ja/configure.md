# カスタム設定

## 方法1：手動編集

ルートディレクトリの `starread.config.ts` ファイルを変更することで、ウェブサイトのタイトル、ナビゲーションメニュー、著者情報、サイドバーコンポーネントの表示など、テーマ設定をカスタマイズできます。

設定項目の例：
```typescript
// ウェブサイトのタイトルを変更
site: {
  title: '私のブログ',
  // ...その他の設定
}

// カスタムナビゲーションメニュー
nav: [
  { name: 'ホーム', href: '/' },
  { name: '概要', href: '/about' },
  // ...その他のメニュー項目
]
```

## 方法2：GUI編集

`pnpm dev` コマンドを使用し、ナビゲーションバーで設定ボタンを見つけてください

> [!warning]
>
> 画像などの静的リソースについては、関連ファイルをpublicディレクトリに配置してください

パラメータを調整した後、設定生成をクリックしてください
